几点说明

  • 选哪个 exe：64 位 Windows 用 KimiPet_x64.exe，32 位系统用 KimiPet_x86.exe。不确定就选 64 位。
  • 直链：表格里的链接就是 github.com/.../releases/download/... 原地址；「复制」按钮复制完整 URL。国内网络打不开时可以用镜像前缀。
  • 校验：同版本的 SHA256SUMS.txt 可用来核对下载文件。
  • 老版本升级：v1.3.2 及更早的程序内下载链路已无法改动，下载 KimiPetUpdater.bat 放到 exe 同目录、退出程序后双击跑一次即可跨过去。
  • 早期版本：v1.0 / v1.1 只发布了 zip，表里如实标注，不会伪造 exe 链接。
  • 关于 exe 本身：单个 exe，首次运行会在旁边生成 KimiPet.ini 和 mod\ 目录；右键「重新加载配置」即时生效。
