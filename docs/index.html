kimi小圆球

一个会自己东张西望的小Kimi，住在你的桌面上。
不占任务栏、不弹窗、不联网也能好好待着；想让它变什么样，全写在一个 ini 里。

它会什么

没有窗口边框，没有设置向导。所有脾气都藏在右键菜单和那个 ini 里。

东张西望

眼神会自己飘，也能设成 follow = 1 一直跟着鼠标看。点它一下会鼓一鼓，连点 5 次它会眯起眼瞪你几秒。

会睡觉

鼠标静止 3 分钟，上下眼睑慢慢往中间合，留一条缝，还有很轻的呼吸起伏。睡着后连点 3 下叫醒；想让它睡踏实，可以设成鼠标怎么动都不醒。

陪你呼吸

球放大 = 吸气、缩小 = 呼气、不动 = 屏息，眼睛跟着睁合，缓入缓出一直循环。等长 / 长呼气 / 慢一点，点一下就写好节奏。

颜色自己加

出厂 8 色。往 [colors] 里加一行，右键菜单立刻多一项，最多 32 个；可以写 HSL、单个基色，也能把 5 层渐变全定死。

能戴挂件

mod\ 里一个 ini 一个模组。眼镜挂在眼睛上、兔耳猫耳从头后面长出来，会跟着球一起缩放、鼓起、歪头。

配置说了算

菜单里的选项由 KimiPet.ini 驱动。改完点「重新加载配置」立刻生效；软件写回时只动那一行，你的注释和顺序都留着。

大小只认 ini

出厂 60px，滚轮和菜单都改不了，只有 size 说了算。size_max 想写多大写多大，离谱的球也可以有。

会自己更新

右键「检查更新…」查 GitHub 最新 Release，后台线程下载、校验、覆盖、重启；球全程照常动，配置文件和模组一个字不动。

一切都写在配置文件里

第一次启动会在 exe 旁边长出 KimiPet.ini（UTF-8）。删掉它，下次启动就是出厂设置。

# KimiPet.ini
[general]
topmost      = 1      ; 始终置顶
follow       = 0      ; 眼神跟随鼠标
autorun      = 0      ; 开机自启
size         = 60     ; 直径 px，只在这儿改
size_min     = 60
size_max     = 420    ; 想要多大的球都行
color        = 淡蓝

sleep        = 1      ; 允许睡觉
sleep_delay  = 180    ; 3 分钟，写 2 就能马上看
sleep_wake_on_move = 1

breathe          = 0    ; 呼吸训练
breathe_in       = 5    ; 吸气：放大
breathe_hold_in  = 0    ; 吸末屏息：不动
breathe_out      = 5    ; 呼气：缩小
breathe_hold_out = 0    ; 呼末屏息：不动

[colors]
; 加一行，菜单就多一项
淡蓝 = #4a86d8,#5a95e0,#6ca4e8,#8cb9f0,#a9cdf6
天蓝 = 201,65,57        ; 色相,饱和度,亮度
朱红 = #ff0000             ; 基色，明暗自动推

[mods]
兔耳 = 1                ; 1 戴上 / 0 摘下

老配置不用手动补。 新版加了新选项，启动时会自己补一行带注释的进去，你原有的值和注释一个都不动。

写回很老实。 软件只替换那一行的值，注释、空行、行序原样保留；中文颜色名也不会乱码。

没权限也能用。 exe 放在 Program Files 这类目录时，配置自动改到 %APPDATA%\KimiPet\，右键「关于」里能看到实际路径。

呼吸训练只是节律引导。 不提供含屏息的具体方案，不写疗效、不监测指标，也不诊断或治疗任何问题；觉得不舒服就关掉，按自己习惯呼吸就好。

挂件挂在哪儿

球体上有一组锚点，坐标以「球半径 = 12」为单位。挂在上面的图元会跟着球缩放、鼓起、歪头；眼睛那两个还会跟着眼神动。

bodyeye_leye_r eyesmouthhead ear_lear_r foot_lfoot_r

mod\ 里一个 .ini 就是一个模组，支持 circle / ring / ellipse / rect / line / arc / triangle 七种图元， 每个都能调偏移、旋转、缩放、透明度和颜色，layer = back 还能画到球后面去。 出厂内置 兔耳、猫耳（白）、锚点调试，默认全关，外观不变； 以后新增的内置模组，老用户更新后也会自动补齐，不会覆盖你自己改过的文件。
